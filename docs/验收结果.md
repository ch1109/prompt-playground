# Prompt Studio v1.0 验收结果（AT01～AT28）

- 执行日期：2026-10-09
- 执行环境：macOS，Node 22.22.3，Next.js 16.3.5（生产构建 `next build && next start`），Chromium（Playwright 1.56.1）
- 命令：`pnpm test`（Vitest，52 项）与 `pnpm e2e`（Playwright，12 项）
- 结果：**Vitest 52/52 通过；Playwright 12/12 通过**

> **重要说明**
> - **没有进行任何真实模型调用**。本机未配置 `MODEL_API_KEY`。模型相关用例（AT22、成功解析路径）使用**本地假 HTTP 服务**验证网关行为，不代表真实模型已运行，也不代表准确率。
> - 样本性质：
>   - `jiuli-v2.0/` 是规格结构示例。
>   - `jiuli-v3.0/` 是九立 Demo 中**真实录制的模型输出**，**不是 Gold**。
>   - `constructed/` 是**人工构造**的负例。
>   - 所有用例只验证渲染与安全行为，不验证识别准确率。
> - 九立连接：只读读取**九立 Demo 本地数据文件**。**九立真实业务只读 API 未接通**，因为现有仓库中不存在这样的接口。
