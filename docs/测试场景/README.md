# 测试场景（四套提示词 + 编造的输入）

用来试「通用提示词 + 输出按业务版式显示」。输入都是编造的数据，不含真实客户信息。

| 场景 | 提示词 | 输入 | 建议版式 |
|---|---|---|---|
| 1 客服工单分类 | `1-客服工单-提示词.txt` | `1-客服工单.xlsx` | 表格 |
| 2 合同条款风险审查 | `2-合同条款-提示词.txt` | `2-合同条款.xlsx` | 清单（通过 / 未通过 + 严重度） |
| 3 会议纪要整理 | `3-会议记录-提示词.txt` | `3-会议记录.xlsx` | 报告 |
| 4 候选人评估 | `4-候选人简历-提示词.txt` | `4-候选人简历.xlsx` | 卡片 |

## 怎么试
1. 新建通用提示词，把「提示词.txt」的内容粘进「提示词」页，保存。
2. 「输入 → 上传文件」选对应的 xlsx，点「运行模型」（第一次会请你确认外发）。
3. 结果出来后点右上角「生成版式」，选建议的形态，点「让 AI 生成」，微调后保存。
4. 再换别的形态（比如把客服工单改成卡片）对比效果。
